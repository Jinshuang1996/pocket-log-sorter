# 使用说明

## 1. 安装

### 使用 DMG

1. 双击 `Pocket色彩分拣器-通用版.dmg`。
2. 将 `Pocket色彩分拣器.app` 拖到旁边的“应用程序”快捷方式。
3. 从 Finder 的“应用程序”打开 Pocket 色彩分拣器。

如果发布包没有经过 Apple Developer ID 公证，macOS 可能提示无法验证开发者。请在 Finder 中右键应用，选择“打开”，再在提示框中确认。不要从不可信的第三方站点下载本应用。

### 从源码构建

```bash
zsh ./test.sh
zsh ./build.sh
```

应用生成到 `dist/Pocket色彩分拣器.app`。

## 2. 添加素材

有两种方式：

- 点击左侧导入区的“点击导入”，可多选视频、JPG、相机 RAW、LRF，也可以选择素材文件夹。整个虚线区域也可以点击。
- 将 MP4、MOV、M4V、JPG/JPEG、相机 RAW、LRF 或整个文件夹拖入虚线区域。

选择文件夹时会递归查找子文件夹中的受支持素材。隐藏文件会被忽略；已经添加的同一路径不会重复加入。

### JPG 与相机 RAW

- `.jpg`、`.jpeg` 统一进入 `07_JPG`。
- `.dng`、`.arw`、`.cr2`、`.cr3`、`.nef`、`.nrw`、`.raf`、`.orf`、`.rw2`、`.pef`、`.srw`、`.x3f` 等常见相机 RAW 统一进入 `08_RAW`。
- 照片会在下方显示缩略图，点击后在上方固定预览区查看；照片不会匹配或导出 LRF。预览右上角可缩小、放大或恢复“适合窗口”，也支持双击在 100%/200% 之间切换和触控板双指缩放；放大后使用滚动手势查看不同区域。
- RAW 缩略图由 macOS ImageIO 解码。系统不支持预览的特殊 RAW 仍可正常分类和导出，只会显示照片占位图。

### LRF 缩略文件

DJI 相机通常会在视频旁生成同名的低分辨率代理文件，例如：

```text
DJI_0001.MP4
DJI_0001.LRF
```

程序按“不区分扩展名大小写、主体文件名完全相同”的规则匹配 LRF。匹配成功时优先从 LRF 读取一帧作为缩略图并用于播放器；LRF 无法解码或播放时自动回退到原视频。LRF 只影响预览速度，不影响 D-Log/HLG/HDR 判定结果。

LRF 可以和视频一起导入，也可以先单独导入。单独导入的 LRF 会暂存在项目的匹配缓存中，等同名视频出现后自动绑定。LRF 不会出现在下方格式分组中，也不会增加素材数量。

## 3. 查看识别结果

分析结束后，底部会出现 D-Log 2、D-Log、D-Log M、HLG、HDR/PQ、Rec.709、JPG、RAW、待确认等分组。视频卡片显示时长，照片卡片显示扩展名。点击卡片后：

- 中间区域播放所选视频，或静态预览所选 JPG/RAW 照片。
- 右侧显示色彩模式、元数据判定依据以及是否匹配 LRF。
- 左侧“项目概览”分别显示视频、照片、LRF 和格式分组数量。

播放器默认优先使用 LRF，以降低高分辨率素材的解码压力。有匹配 LRF 时，可以点击播放器下方的“播放原片”或“播放 LRF”随时切换。

右侧环形图使用与下方分组一致的颜色，显示每种色彩格式的素材数量和百分比。“待确认”也会单独计入，便于快速发现需要人工核对的素材。

只有下方格式分组区域可以滚动：在底部空白处横向浏览其他格式，把指针放在某个格式列内即可独立上下浏览该列素材。一个格式拥有大量文件时不会拉长其他格式，也不会在短分组下方产生长距离空白。所有格式列始终保留，方便确认当前为空的类型；导入区、播放器、环形图和导出控制始终保持固定。

| 显示 | 含义 | 后期建议 |
|---|---|---|
| D-Log 2 | Pocket 4P D-Log 2 | 使用 D-Log 2 对应 LUT |
| D-Log | Pocket 4/4P D-Log | 使用 D-Log 对应 LUT |
| D-Log M | 其他 DJI 机型的 D-Log M | 不要与 D-Log/D-Log 2 LUT 混用 |
| HLG | Rec.2100 HLG | 使用 HLG/HDR 色彩管理流程 |
| HDR | PQ、Dolby Vision 或明确 BT.2020 HDR | 按素材元数据配置 HDR 时间线 |
| 普通 Rec.709 | 相机直出普通模式 | 通常不需要还原 LUT |
| JPG | 相机 JPEG 照片 | 进入 JPG 照片处理流程 |
| RAW | 相机 RAW 原片 | 进入 RAW 解码与调色流程 |
| 待确认 | 证据不足 | 在分类前人工检查 |

将鼠标停在缩略图上可以查看程序读取到的元数据摘要。

## 4. 选择输出目录

点击右侧“选择输出文件夹”，选择一个有足够空间的位置。程序只创建实际用到的分类文件夹。

建议不要把输出目录选在待扫描素材文件夹内部，否则下次递归扫描可能把分类副本再次加入。

## 5. 选择需要导出的素材

新导入的视频默认全部勾选。每张缩略图右上角都有独立选择按钮：

- 点击缩略图主体：只切换播放器当前素材，不改变导出选择。
- 点击圆形勾选按钮：加入或移出导出列表。
- 点击“全选”：选择当前项目的所有视频和照片。
- 点击“取消全选”：清空导出选择。

右侧按钮会显示“导出已选 N 个”。未勾选的素材不会被复制或移动。

## 6. 复制或移动

- **移动原片（默认）**：将原文件移动到分类目录，节省磁盘空间，但会改变原路径。
- **复制原片**：保留原始素材，创建分类副本。重要项目、首次使用或剪辑工程已经引用源路径时应主动切换到此项。

“同时导出匹配的 LRF”默认开启。开启后，LRF 会与对应视频进入同一个色彩格式目录，并尽量保持与视频一致的主体文件名；关闭后只导出视频。

目标目录存在同名文件时，程序自动生成 `_2`、`_3` 等名称，不覆盖任何文件。

## 7. 输出结构

```text
所选输出目录/
├── 01_D-Log_2/
├── 02_D-Log/
├── 03_D-Log_M/
├── 04_HLG/
├── 05_HDR/
├── 06_Normal_Rec709/
├── 07_JPG/
├── 08_RAW/
└── 99_待确认/
```

## 8. 为什么会进入“待确认”

常见原因：

- 文件不是 DJI 相机原始文件，或被剪辑软件重新封装。
- 软件无法找到 `djmd` 数据轨。
- 文件采用 fragmented MP4（包含 `moof`）。
- 新固件使用了尚未收录的 `ColorGammaSxS` 数值。
- 文件只标记 BT.709。BT.709 不能单独证明它是普通模式，因为部分 Log 素材也使用 BT.709 容器标签。

程序宁可进入待确认，也不会仅根据画面明暗或位深强行猜测。

## 9. 隐私和数据安全

- 视频与照片分析完全在本地进行。
- 软件不访问网络，也不上传素材。
- 软件不修改视频容器内部的元数据。
- 默认移动原片，且永不覆盖同名文件；如需保留源目录，请在导出前切换为“复制原片”。
- “移动”会改变源文件位置，请确认剪辑工程没有依赖旧路径。

## 10. 常见问题

### 点击“导出已选”没有反应

需要先完成文件分析、至少勾选一个素材并选择输出文件夹。按钮变为高亮后才能执行。

### 找不到 LRF 或没有缩略图

确认 LRF 与视频位于同一目录且主体文件名完全一致。若相机未生成 LRF，程序会直接读取原视频；某些编码无法被当前 macOS 的 AVFoundation 解码时，卡片会显示视频占位图，但元数据分类仍可正常进行。

### D-Log 2 被放入待确认

确认文件是相机原始 MP4/MOV，而不是经过微信、网盘转码或剪辑软件导出的版本。请在 Issue 中提供匿名化元数据和相机固件版本，不要公开上传私人原片。

### DMG 可以安装到哪些 Mac

构建脚本生成 Universal Binary，支持 Apple Silicon 和 Intel 64 位 Mac，最低系统为 macOS 13。
